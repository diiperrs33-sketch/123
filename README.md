# Hotel Aurora — Agenda 13

Projeto da Agenda 13 de Programação Mobile I.

**Desenvolvedor:** João Andrade  
**Ano:** 2026

O aplicativo foi feito com C#, XAML e .NET MAUI. Na tela de reserva, dá pra escolher quantos adultos e crianças vão ficar, selecionar o quarto e informar as datas. Depois aparece um resumo da hospedagem e o total.

Também tem a tela **Sobre**, com o nome do desenvolvedor, o ano e uma explicação rápida do projeto.

Usei os componentes Stepper, Picker, DatePicker e BindingContext, que aparecem na apostila.

Os valores são exemplos, não é uma reserva de verdade.

## Como executar

Abra a solução `HotelAurora.sln` com o VS Code e as ferramentas .NET MAUI instaladas. Você precisa de um dispositivo ou emulador compatível para rodar.

**Pra entregar:** execute o aplicativo, abra a aba Sobre e tire um print real. Depois compacte o print num ZIP e envie junto deste link do GitHub.

Obs.: as prévias ilustrativas, quando houver, não são prints reais do aplicativo.
